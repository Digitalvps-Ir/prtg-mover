How it works

  1. Servers — add the source PRTG server and the target(s). Choose the connection method: RDP (nothing to configure on the server) or WinRM.
  2. Test — Test RDP / Test WinRM. A server is PASS when at least one method works.
  3. Agent (RDP method) — press RDP, log in, run the copied command in an elevated PowerShell. Keep the RDP window open or minimized — do not close it while a job runs.
  4. Migrate — pre-flight checks → copy PRTG from a snapshot straight to this manager (source untouched) → package → restore on each target → start PRTG and verify it is fully up.
  5. Backups / Jobs / Logs — download the package, follow every step live, resume failed jobs, download diagnostics.

3 · What to include

Transfer

RDP and WinRM copy the files through this computer. WireGuard and IPIP build a tunnel between the two servers, then WinRM (TCP 5985) carries the files from one tunnel address to the other. This computer sends commands and does not keep the backup.

4 · Source server

Restart & verify starts core + probe and waits until both services run, the web interface answers and everything is still stable after 45 s — otherwise the job fails. For a real migration keep the old server stopped (two cores with the same license would alert twice).
