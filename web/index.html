How it works

  1. Add servers — the source PRTG server and one or more targets (WinRM must be enabled, see README).
  2. Test — verifies remoting, admin rights, PRTG version, disk space and VPN list.
  3. Migrate — stops PRTG on the source, packages data + registry + customisations + VPN + desktops, stores the package on this manager, restores it on every target and starts PRTG.
  4. Verify — the job waits until the PRTG web interface answers on each target.
