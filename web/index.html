How it works

  1. Servers — add the source PRTG server and the target(s). Choose the connection method: Local (PRTG Manager on the PRTG server), RDP or WinRM.
  2. Test — a server is PASS when at least one method works.
  3. Backup & Migrate — a full backup / migration, or only history, devices, notifications, triggers or the license.
  4. Backups — validate, inspect, download and restore every package, always with a preview first.
  5. License — see the license state, enter a trial or bought key, back it up, restore or remove it.

PRTG license

License state of a PRTG server, entering a trial or bought key, license backup, restore and removal. PRTG activates every key itself with Paessler — PRTG Manager never bypasses or fakes the activation.

Choose a server and press Refresh status.

Actions

Where license keys come from

  • Trial: register on paessler.com/prtg/download — Paessler sends the trial license name and key by e-mail.
  • Bought / site license: the Paessler shop (shop.paessler.com) shows your license name and key. Paessler has no public interface that hands out keys, so PRTG Manager cannot fetch one by itself — it activates the key you enter.
  • Activation happens in PRTG itself, online with Paessler. Without internet access use Setup › License Status › offline activation in the PRTG web interface. A key active on another system must first be moved in the Paessler shop (Activation Center) or by Paessler / your reseller.

Activate license

PRTG is stopped for a moment, the key is written the way the PRTG Administration Tool does it, PRTG is started and the activation result is read from the PRTG log. A copy of the current license is kept on the server.

Back up license

The license name, key and activation data are encrypted on the server with this password. Keep the password — it is needed to restore the license.

Remove the PRTG license

License name and key (and PRTG's activation data of this key) are removed from the PRTG on this server. PRTG is restarted and runs without a license until a new one is entered. Configuration and history stay. A copy of the removed license data is kept on the server. Paessler has no remote deactivation: to use the key on another system, move the activation in the Paessler shop.
